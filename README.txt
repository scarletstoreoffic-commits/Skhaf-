ШКАФ — маркетплейс вещей (проект МФЮА)

Этап 1 (HTML + CSS + JS): просто открой index.html двойным кликом.
  Данные хранятся в браузере (localStorage).
Этап 2 (Python + SQLite): запусти  python server.py  и открой http://localhost:8000
  Те же страницы, но данные лежат в базе market.db (создаётся сама).

index.html — структура страницы | style.css — оформление | script.js — логика
server.py — сервер | market.db — база SQLite | config.json — категории, города, порт

База данных: market.db (SQLite). Открыть и посмотреть таблицы можно в программе
"DB Browser for SQLite" или в VS Code (расширение "SQLite Viewer").
Таблицы: users, listings, orders, messages.

users.json — список пользователей в обычном тексте (открывается в Блокноте).
Обновляется сам при запуске server.py и при каждой новой регистрации.

Импорт / экспорт: кнопка ⇅ в шапке. Выгрузка — JSON (с фото) или CSV (для Excel, разделитель «;»).
Загрузка — перетащи .json или .csv в окно; шаблон CSV скачивается там же. Работает в обоих режимах.

Отзывы: после покупки сразу открывается окно с оценкой звёздами, готовыми фразами и своим текстом. Отзывы видны в карточке товара, оставить можно и позже на странице «Заказы». В базе новая таблица reviews (создаётся сама).

Анимации: полноэкранный заголовок «ШКАФ» → при прокрутке вращается карусель одежды → карточки товаров влетают и крутятся.
Всё написано без библиотек и без интернета (код — в конце script.js, блок «СЦЕНА»).
